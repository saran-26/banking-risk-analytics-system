# Predictive Banking Analytics & Risk Intelligence System

## Overview
This project is an AI-powered banking analytics system developed using Machine Learning and Power BI to analyze customer financial data and perform predictive risk analysis.

## Features
- Data preprocessing and cleaning
- Predictive risk analysis using Random Forest
- Banking analytics dashboard using Power BI
- Business insights visualization
- Loan approval trend analysis

## Technologies Used
- Python
- SQL
- Machine Learning
- Power BI
- Pandas
- Scikit-learn

## Machine Learning Model
- Random Forest Classifier

## Tools & Libraries
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Power BI

## Project Workflow
1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis
4. Model Training
5. Prediction & Evaluation
6. Dashboard Visualization

## Output
The project generates predictive insights and interactive dashboards for banking risk analysis and business decision support.
